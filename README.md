# Resume-Based Job Matcher 🔍💼

A Node.js + Express + MongoDB backend that allows users to upload resumes, extracts key information (skills, experience, job titles), and searches for relevant job listings using job search APIs.

## ✨ Features

- Upload and analyze resumes (skills, job titles, experience)
- Resume parsing via AI or third-party API
- Smart job search based on resume content
- Integration with Job Search APIs (e.g., JSearch)
- User authentication and job saving 

## 🧱 Tech Stack

- Node.js + Express
- MongoDB + Mongoose
- OpenAI / Resume Parser API (for resume analysis)
- JSearch API (or any job listing API)
